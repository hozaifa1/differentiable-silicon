# factor a matrix. libopenblas-dev (see tesseract_config.yaml) is enough to make
# `import devsim` succeed and is not enough to run anything: devsim picks its
# direct solver from whichever math library it loaded, and with OpenBLAS it picks

# SuperLU either. Without this line the image builds, passes `tesseract check`,
# serves, answers abstract_eval, publishes the frozen schema, and then returns
# HTTP 500 on the first apply that has to solve. Same reason the `devsim` extra in
# pyproject.toml pins it. See diffsilicon.shared.devsim_env.
